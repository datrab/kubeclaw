# Code of Conduct

KubeClaw contributors are expected to keep collaboration direct, respectful, and useful.

## Expected behavior

- Discuss code, behavior, and evidence rather than personal intent.
- Give reviewers enough context to reproduce issues.
- Keep disagreements focused on source truth, user impact, and maintainability.
- Avoid harassment, threats, insults, discriminatory language, or sustained disruption.

## Enforcement

This repository does not yet publish a dedicated community moderation contact. Until maintainers choose one, report conduct concerns through the same private channel used for repository access or maintainer coordination. The missing public contact is tracked in `docs/open-issues.md`.
