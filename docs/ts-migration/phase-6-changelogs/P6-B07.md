## Behavior changes

### DELETE_LEGACY
- Deleted Forge completion missing-repo-root no-work authority.
  - `collectMeaningfulForgeDiffEvidence()` now returns typed failure evidence with `FORGE_COMPLETION_REPO_ROOT_REQUIRED` instead of reporting OK/no meaningful changes from absent repo context.
- Deleted generic polling no-repo Git skip.
  - Polling Git sync now returns `POLLING_REPO_ROOT_REQUIRED` as a typed `git_error` instead of silently skipping Git evidence when `repo_root` is absent.
- Deleted ACP session-monitor Forge readiness fallback.
  - Closed/error ACP session state without canonical `agent.ended` hook evidence now returns a typed `agent_ended_missing` failure result with sanitized transcript diagnostics; ACP monitor state no longer authorizes Forge readiness/no-work through fallback diff classification.

### STRICTIFY_TS_SLICE
- Strictified session-end Git polling and worktree signatures.
  - `pollForSessionEnd()` now requires typed `repo_root` context before collecting initial/final worktree signatures.
  - Worktree signature collection errors now return typed `git_error` results with `POLLING_WORKTREE_SIGNATURE_FAILED` instead of collapsing to an empty signature.
  - Missing `repo_root` during session-end polling now returns `POLLING_REPO_ROOT_REQUIRED` instead of skipping pull/signature evidence.

### KEEP_TYPED_POLICY retained
- Agent-observability Forge diff classification still excludes control/runtime artifacts (`forge-completion.json`, `status.json`, `.swarm/**`, logs, and configured ignored paths) from meaningful work evidence.
- Forge Git evidence failures remain typed poll failures (`git_error`) rather than thrown/unshaped exceptions.
- Buster completion target-specific default expected statuses remain typed adjudication policy.
- Invalid Redis completion payloads still fail closed as terminal invalid evidence.
- Completion cancellation still returns typed aborted results.
- Malformed local gate output still fails closed as invalid contract evidence.
- Completion conflict/drift and stale Redis completion authority still fail closed/preserve local terminal truth.
- Redis completion event adapter blocked-XREAD lifecycle defaults and intentional abort cleanup remain intact.
- Local evidence adapters still support nearest-existing-directory watch, debounced changes, and optional existing evidence emission.
- Buster module completion adapter fatal errors and unresolved evidence still fail closed.
- Missing session key remains fail-closed for session lifecycle polling.
- Subagent transcript mirroring and timeout nudges remain non-authoritative evidence/operator side effects.
- Polling parse-corruption threshold and ACP terminal no-output/no-change envelopes remain explicit typed poll results.

## Typed/runtime implementation notes

- Migrated owners use native Node erasable TypeScript style with explicit relative `.ts`/`.js` imports.
- Type-only/runtime-transform syntax was not introduced; no enums, runtime namespaces, parameter properties, decorators, import-equals, path aliases, or angle-bracket assertions are used.
- Existing compatibility projection seams remain isolated at external adapter/test boundaries and do not authorize terminal polling/completion state.
