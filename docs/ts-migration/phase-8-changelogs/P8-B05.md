# P8-B05 — Approval and Remediable Gate Runner Policy

## Scope

- Audited approval gate state/control/runner helpers and the shared remediable gate engine against the Phase 8 fallback ledger.
- Locked approval audit degradation, timeout policy semantics, remediable fix outcome typing, and gate fix Git persistence degradation with focused contract coverage.
- Updated migration docs for the hardened approval/remediation policy.

## Fallback-Ledger Decisions

- `P3-057` is resolved as `STRICTIFY_TS_SLICE`: approval audit artifact writes remain nonterminal, but failures emit typed durable operator evidence through `approval_audit_write_failed`.
- `P3-058` remains `KEEP_TYPED_POLICY`: approval timeout `CONTINUE` and `BLOCK` are explicit typed approval policy values; `CONTINUE` maps to pass/proceed only when represented in timeout metadata.
- `P3-059` is resolved as `STRICTIFY_TS_SLICE`: gate Forge fix Git persistence may degrade without blocking local retest, but degradation is surfaced as typed fix outcome evidence and no longer described as durable commit success.
- Remediable gate controller and fix outcome compatibility is strictified: fix attempts must return the typed `terminal` / `retry_request_fix` / `re_evaluate` union before the engine loops.

## Changes

- Updated `gate-forge-fix-cycle.ts`:
  - added typed `gate_fix_git_persistence_degraded` evidence for failed/noncommitted soft-fail Git publication;
  - changed the default degraded success presentation to say local worktree retest instead of committed success;
  - returns degraded Git persistence state with the typed `re_evaluate` fix outcome.
- Updated `remediable-gate-engine.ts` so legacy control-result-only fix outcomes fail validation; the engine now requires a typed fix outcome mode and carries degraded fix outcome state into re-evaluation.
- Updated focused contracts:
  - approval audit failures must append durable operator evidence;
  - approval timeout policy metadata must remain explicit and `timeout_continue` must validate as typed pass policy;
  - gate fix cycles must surface Git persistence degradation;
  - remediable fix outcomes must use the typed union.
- Updated Phase 8 status and architecture/authority/import-call-graph docs for approval/remediation ownership.
