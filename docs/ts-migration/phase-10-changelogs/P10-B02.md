# P10-B02 Executable Runtime And Tool Delegates

Date: 2026-05-29

## Summary

P10-B02 settled the executable `.js` delegate surface. Production Nova/Buster runtime entrypoints remain `.js` compatibility paths, but obsolete root tool aliases were removed from active config/docs in favor of the canonical `/app/skills/pipeline/tools/*.ts` locations.

## Changes

1. Added `tests/verification/contracts/check-phase10-executable-delegate-surface.mjs`.
2. Added the executable delegate contract to the shared contract suite and wrapper drift guard.
3. Updated chart config pre-check path from `/app/skills/lint-report.ts` to `/app/skills/pipeline/tools/lint-report.ts`.
4. Updated active behavior fixtures and operator docs away from removed root tool aliases:
   - `/app/skills/lint-report.ts`
   - `/app/skills/redis.ts`
   - `/app/skills/project-summary.ts`
5. Updated Buster values guidance so subagents stop after writing artifacts instead of invoking the removed direct Redis completion action.
6. Recorded the retained executable delegate decision in the Phase 10 docs.

## Retained Delegates

- `skills/buster/buster-pipeline.ts`: retained as the production Buster executable adapter for `node /app/skills/buster-pipeline.ts`; delegates to `buster-pipeline.ts` and has no helper barrel exports.
- `skills/nova/pipeline.ts`: retained as the production Nova executable/public API adapter for `node /app/skills/pipeline.ts`; delegates direct execution to `pipeline/cli.js`.
- `skills/nova/pipeline/cli.ts`: retained as the CLI facade over `cli.ts`.
- `skills/nova/pipeline/tools/lint-report.ts`: retained as the lint-report executable facade over `lint-report.ts`.
- `skills/nova/pipeline/tools/project-summary.ts`: retained as the project-summary executable/library facade over `project-summary.ts`.
- `skills/nova/pipeline/tools/redis.ts`: retained as the Redis executable/library facade over `redis.ts`.

## Ledger Compliance

- `KEEP_TYPED_POLICY`: retained executable direct-entry guards and tool exit/notification policies as external adapter policy.
