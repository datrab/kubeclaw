# Nova project runtime

The [canonical project runtime guide](../../skills/nova/project/README.md) ships inside the Nova bundle at `/app/skills/packages/nova-project/README.md`. It describes the project contract, compilation, execution, recovery and current acceptance limits.

The lifecycle core remains independent of product stage names. The product compiler lives in `skills/nova/project`; the packaged launcher uses `@kubeclaw/nova-project/cli`.
