# Extensibility Model

Status: current with planned gaps
Audience: developers, maintainers

## Overview

KubeClaw is intended to be extended through pipeline features, gates, Buster suites, hooks, plugins, verification checks, linting rules, and observability sinks. Current extension docs are thin and will be rebuilt from source during the pipeline and developer phases.
