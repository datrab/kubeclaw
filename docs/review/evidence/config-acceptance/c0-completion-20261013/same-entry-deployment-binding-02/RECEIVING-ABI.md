## Errors and effect-free order

The proposed receiver must reject before any secret/provider/DB/API/listener/staging effect:

1. Unknown/duplicate JSON keys, unsupported root/schema version, missing closed root member, default/coercion/old-fragment fallback, unknown paths, noncanonical relative path, absolute/`..`/include/symlink/late ENV overrides.

Controller B TTL domain must preserve old A native status/finalizer compatibility or reject/drain publication. 6. Verify complete input file-set and source/image/schema/role generation identity, produce readonly outputs and exact output receipt, verify receiving physical bytes, then and only then permit the separately approved decoder/business startup. No current implementation is claimed.

## Hash codec and receipt, without circular identities

`file-set-stand.json` lists exact paths/bytes/SHA256 for all bounded input owner/schema members. Raw SHA256 means the original exact bytes, not JSON reserialization.
