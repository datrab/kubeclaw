## Current facts reconciled with retained proposals

1. **Buster network ceiling is a rejection boundary, not a clamp.** Actual requested timeout/response must be positive integers≤captured native ceilings; overage rejects before fetch. Providers compute their actual request timeouts from owned/task/invocation values; full association has1000ms/4096byte native ceilings, admitting exact50/500ms and32/2048byte provider pairs. Real grants/fences/fixture authority remain separate.
2. **Nova network adapter is a different path.** It captures profile once, ignores per-request timeout/response settings, JSON.stringify's request body, counts decompressed response bytes, decodes JSON and rejects non2xx. Buster accepts already-string request bodies, returns raw response/status/digest including non2xx, and supports websocket under `network.http` operation`websocket`. No `network.websocket` capability is invented. Method/schema and timer/parser differences remain explicit.
3. **API-flow retains a real hidden precedence issue.** Valid step.timeout500 masks invalid root0 in current code; source quota read-before-check and total setup/main/cleanup count are distinct. Target rejects retired step/task quotas even equal before effects. Files, endpoints, steps and assertions remain task intent.
4. **OpenAPI's source processing/safety policies are not just two root quotas.** Spec4MiB, selections128, schema/ref depth64, regex length256/quantifier1024 and supported-dialect/security checks are captured with explicit supplemental integration obligations, not claimed globally complete by copying defaults into a schema.
5. **Declaration metadata cannot invent safe semantics.** Complete baseline declaration policies are materialized; selected current API-flow/OpenAPI package retrySafe=false is fixed false in active candidate schemas. Generic original boolean domains/cases remain history; a different genuinely supported package/task/native contract is required before upward true is allowed. HTTP true may conservatively disable retry. MatrixFields may name task fields only, never retired processing quota authors. All original declaration ALT/MUT/BIND obligations remain required, and no unsupported positive alternate is manufactured.
