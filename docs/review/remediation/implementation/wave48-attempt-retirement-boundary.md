# PCR-OBS-002: measured remaining Attempt quota and consumer boundary

Status: **incomplete; not a new closure**. Source base `147a9e0` has the reviewed
Admission retirement and original Snapshot version integration. This package
adds two executable boundary regressions; it does not change production source,
quotas, run authorization or deletion policy.

## Actual boundary proof

The existing real filesystem test now uses a maximum of **two result records**:
one from the completed owner and one owned by an actual waiting run. Both run
lifecycle histories are generated by the original Nova Core with the existing
Git/repair-budget plugin. These are original Store/Consumer tests with explicitly
constructed WorkerResult inputs, not a claim of a live Buster provider or model
execution.

The original `NovaObservabilityReconciler` consumes the first completion,
validates its required closure/evidence and fsyncs an `imported` decision with
`complete` observations into the actual reconciliation journal. No caller-made
ACK replaces this step. Original Admission retirement then releases **7,177
bytes** in this fixture. The Attempt file is byte-for-byte unchanged, both result
slots remain occupied, and the next write still fails with
`OBSERVABILITY_RESULT_STORE_FULL`.

Reopening the original stores and replaying the old result yields its original
identity. Reconciliation returns `already-imported` without appending to its
journal. The actual waiting run's event bytes are unchanged. This proves the
remaining quota boundary and preservation of these consumers, **not** that a
result-retirement implementation already exists or that a newly dispatched
external action was exercised.

A separate disposable corruption negative removes the original result while
retaining its genuine import journal. Admission raw reads and duplicate delivery
fail closed with `admission-retirement-source-result`; the producer's pending
outbox is retained. Restoring the original source allows the original duplicate
ACK and `already-imported` replay again. No production cleanup command performs
this deliberate test corruption.

## Exact next implementation action

Implement an explicit persisted Attempt-v2 result projection **only for an
already imported redundant result copy**, not deletion of the authoritative
completion. Retain full completion intent, receipt, result identity and evidence
metadata; replace only the duplicate WorkerResult payload with a bounded
reference to its existing canonical import-journal record. Resolve this before
every logical Snapshot consumer and count only resident result payloads against
the resident-result quota, while charging all retained reference/tombstone bytes
against the existing metadata limit. State publicly that closures, original
evidence and metadata quota remain finite.

Do not use a sidecar archive as a fake capacity release or bypass quota checking
on inflated logical snapshots. All writers must preserve the compact persisted
variant on subsequent updates. Bind journal path to the canonical run root,
retain full hash-chain validation and exact sequence/hash/owner/result matching,
and keep explicit read caps plus no-follow/non-regular-file rejection.

The operator wrapper needs original Run/Attempt fencing and a validated,
unchanged import checkpoint at the atomic transition. Inventory must include
the nested reconciliation journal; the current root-journal summary alone does
not validate this nested authority. Do not introduce a Foundation dependency on
the Nova engine merely to parse a journal. The shared parser contract and every
existing direct Attempt-file reader must move together if that is the selected
implementation.

Required new acceptance: true resident-result quota release for the same mixed
owners, old Store and Admission replay without reinsertion/new execution,
unchanged Clawdeck/completeness/evidence, v1 reopen, missing/tampered/foreign/
unimported checkpoint rejection, active run rejection, stale scope/CAS,
concurrent writer exclusion, process death before transition and after durable
transition, and retry after restart. Existing Admission crash tests are not
evidence for the as-yet-unimplemented Attempt transition.

This redundant-copy slice needs no new permission to delete logs or results:
none are deleted. Broader evidence deletion still needs an explicit disposition
ending reopening/acceptance honored by all consumers; terminal state or Demo TTL
does not supply it. PCR-OBS-002 remains open until its connected release contract
is implemented and passes its original full acceptance.
