# Supervisor state admission and observable resource gaps

Root found a second concrete admission defect while addressing the six remaining canonical lint errors. `optionalJson` treated any read/parse error as an absent file. An existing corrupted lease, or a syntactically valid lease with no owner, could therefore be removed and replaced. A malformed heartbeat was also silently ignored. These are not proofs that an earlier owner stopped.

The new original-CLI regressions fail three times against268bb72: corrupted lease JSON, unknown-owner lease `{}`, and malformed heartbeat all incorrectly return success from the real status reader. A fourth case with the actual test process as live lease owner already passes. The correction only treats ENOENT as absent, reports other JSON read/parse failures with their cause, and requires the existing lease schema plus nonempty instance/run identity and positive integer owner PID before considering replacement. Unknown leases are preserved byte-for-byte. A heartbeat failure releases only the new supervisor's own lease through the existing finally path.

Optional resource observations remain noncritical: actual proc/cgroup read failures are recorded as additive `observationErrors` containing file and error code/name, with unavailable measurements omitted. They do not become zero measurements or successful ownership evidence. The redundant explicit `env: process.env` option was removed; Node's original spawn behavior inherits the same environment. Initial start/recover mode selection has a named helper. No lint rule, allowance, baseline or test assertion was weakened.

Root verification on the corrected source: **17/17 original and new Supervisor tests pass, zero skips**. This includes actual pipeline start, both stop signals during recovery, original status failures, existing operations checks and the new persisted-state negatives. Canonical lint for the changed source/test is now **0 errors**, replacing the six earlier errors. Raw before/after output and exact commands are under `docs/review/evidence/resume-84-supervisor-state-root/`.

This is a bounded improvement, not complete durable process ownership. Concurrent stale-lease replacement, PID reuse/permission ambiguity and native adopted-process identity/status acceptance are not established by these tests. No adopted native gate was retried and no process identity, procfs or cgroup result was mocked. PCR-SCAFFOLD-OPS-001 remains partial.
