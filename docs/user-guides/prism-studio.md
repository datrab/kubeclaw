# Prism Studio user guide

1. Open the private Tailscale Studio address.
2. Select a design direction.
3. Use the visual editor to insert, move, copy, edit, or remove components.
4. Use Preview mode to test screens, states, and flows.
5. Review all blocking and review findings.
6. Approve the exact revision.
7. Publish its immutable Baseline Bundle.

Puck supplies editor controls. Puck does not own the design. Prism stores only
the validated Design Document and typed edit operations.
