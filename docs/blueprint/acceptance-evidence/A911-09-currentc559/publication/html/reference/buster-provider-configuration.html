How To Read The Tables

A dotted name is an object path. [] identifies each array item. {} identifies each value in a map. “Required” means that the immediate parent always requires the field. “Conditional” means that a oneOf or anyOf choice introduces the field. The selected choice can require it, while another valid choice can omit it. “Optional” means that no applicable schema rule requires it. Read the choice rules after the table to learn which branch applies. The JSON Schema remains the validation authority. This page makes that authority visible; it does not replace it.

The generator records types, defaults, constants, allowed values, numeric and size limits, patterns, uniqueness, and closed-object rules. It intentionally does not invent a default when the schema has none.
