Coverage boundary

These references cover current authored configuration and the readers that consume it. Registration-specific configuration remains canonical in the recursive plugin catalogue, while runtime events and progress records are outputs rather than authoring inputs. An absent value grants no authority: check the owning contract before adding a field, port, package, or credential.
