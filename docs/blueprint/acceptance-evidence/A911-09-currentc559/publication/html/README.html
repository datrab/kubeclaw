Three Connected First Journeys

  • Architecture readers start with Understand KubeClaw.
  • Operators start with the Operator Quickstart, then continue to Configure and Operate.
  • Plugin developers start with Create and Activate a First Pipeline Plugin.

The operator route does not yet supply a self-contained first pipeline input. It requires operator-owned platform and project files. The Configure and Operate page states their command boundary.

Documentation Tracks

  • Understand explains architecture, authority, runtime flow, and system boundaries.
  • Operate explains planning, installation, daily operation, diagnosis, recovery, maintenance, and retirement.
  • Extend explains plugin authoring, testing, packaging, and supported extension points.
  • Reference contains generated facts from current source, configuration references, and the glossary.
  • Current Status links current work, local closure and separate live acceptance.
  • Open issues lists remaining implementation work and completion criteria.
  • Roadmap explains planned platform improvements and why they matter.
  • Decisions records enduring constraints, their rationale and approval evidence.
