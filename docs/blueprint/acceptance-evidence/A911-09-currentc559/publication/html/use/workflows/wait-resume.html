This guide supplies a complete disposable approval input set. Nova executes the installed human-approval stage, persists a wait, and sends its request to a notification receiver. An operator then supplies one decision. Nova records that decision and starts a second attempt. The second attempt returns passed without sending another notification.

The canonical run-control procedure owns the start, audit, signal, and recovery rules. Follow those rules throughout this exercise. The concrete commands below bind that procedure to this input set. An approval here concerns the disposable rehearsal request. It is not demo or product acceptance.

Execution status: input schemas, focused plugin boundary/guidance checks, receiver contract checks, and runtime registration validation passed within their local scope. Runtime validation selected the installed stage and four adapters; it did not start an approval run. These checks do not establish a completed local wait/resume lifecycle. The full local rehearsal has no successful execution evidence. The mandatory deployment wait/resume run remains open and unexecuted.

Input Set

Use these three files from the same checkout:

Input Exact file Meaning
Pipeline approval.pipeline.json One approval stage of type kubeclaw.decision.human-approval; no dependent stage or external product change.
Platform template platform.template.json Exact registrations, grants, loopback receiver, secret selector, and storage placeholders. Materialize a private copy before use.
Signal template signal.template.json All eight required envelope fields and the approval payload. Replace its identities and deliberately stale time from the new durable wait. Never submit the unchanged template.

The wait-stage package is skills/nova/plugins/human-approval/plugin.json, registration kubeclaw.human-approval:approval, module src/stage.ts, export execute. This exercise uses the generic approval registration, not the separate architecture approval registration. Generic approval accepts a summary and an operator decision; it does not bind a source/report digest. Use a separate contract when that binding is required.

The pipeline sets maxAttempts: 2, maxRemediationCycles: 0, timeoutMs: 10000, and timeoutMinutes: 60. The initial waiting attempt consumes one attempt. The resumed attempt consumes the second. Setting maxAttempts: 1 would exhaust the attempt budget when the stage tries to wait. The 60-minute expiry limits when Core accepts the decision. It is distinct from the 10-second stage execution limit. This guide schedules no retry or remediation.

The platform selects these providers and grants:

Consumer Capability and provider Effective scope
kubeclaw.human-approval:approval signal.wait → kubeclaw.wait-store:waits approval.resolved, issuer ID operator:local
Same stage operator.request → kubeclaw.operator-messaging:operator Target operators
Operator adapter network.http → kubeclaw.network-http:http Loopback origin http://127.0.0.1:18765; POST, listed headers, and byte/time limits also enforced by adapter configuration
Operator adapter secrets.read → kubeclaw.secret-resolver:secrets Secret name operator.webhook, selected from environment variable WAIT_REHEARSAL_WEBHOOK_KEY

The notification adapter signs its HTTP body with an HMAC key. That transport signature authenticates the notification to this local receiver. The later resume envelope is unsigned. Its issuer is self-asserted by the file's creator. Restricted signal creation and CLI access are the effective operator authority; issuer matching does not authenticate a person.

import fs from 'node:fs';
import path from 'node:path';
import http from 'node:http';
import crypto from 'node:crypto';
const root = process.env.WAIT_REHEARSAL_ROOT;
const key = process.env.WAIT_REHEARSAL_WEBHOOK_KEY;
if (!root || !key) throw new Error('Restricted receiver configuration is required');
const file = path.join(root, 'receiver.jsonl');
const server = http.createServer(async (req, res) => {
  if (req.method !== 'POST' || req.url !== '/messages') { res.writeHead(404); res.end(); return; }
  const chunks = []; let size = 0;
  for await (const chunk of req) {
    size += chunk.length;
    if (size > 16384) { res.writeHead(413); res.end(); return; }
    chunks.push(chunk);
  }
  const body = Buffer.concat(chunks).toString('utf8');
  const id = req.headers['idempotency-key'];
  const signature = 'v1=' + crypto.createHmac('sha256', key).update(`${id}.${body}`).digest('hex');
  if (!id || req.headers['x-kubeclaw-signature'] !== signature) { res.writeHead(403); res.end(); return; }
  fs.appendFileSync(file, JSON.stringify({ idempotencyKey: id, payload: JSON.parse(body) }) + '\n', { mode: 0o600 });
  res.writeHead(202, { 'content-type': 'application/json' });
  res.end(JSON.stringify({ messageId: 'wait-rehearsal-local' }));
});
server.on('error', error => { console.error(error.message); process.exitCode = 1; });
server.listen(18765, '127.0.0.1', () => console.log('Local receiver ready on 127.0.0.1:18765'));
process.on('SIGINT', () => server.close());

authority_snapshot() {
  node --input-type=module - "$1" "${2:-}" <<'NODE'
import fs from 'node:fs';
import path from 'node:path';
import crypto from 'node:crypto';
import assert from 'node:assert/strict';
import { parseHashJournal } from './skills/common/plugin-runtime/foundation/observability/hash-journal.ts';
const root = process.env.WAIT_REHEARSAL_ROOT;
const run = fs.readFileSync(path.join(root, 'run-root.txt'), 'utf8').trim();
const files = {
  events: path.join(run, 'events.jsonl'), effects: path.join(run, 'effects.jsonl'),
  signals: path.join(run, 'signals.jsonl'),
  waits: path.join(root, 'waits/records/store.json'),
  deliveries: path.join(root, 'deliveries/records/store.json'),
  receiver: path.join(root, 'receiver.jsonl'),
};
const hashes = Object.fromEntries(Object.entries(files).map(([name, file]) => {
  if (!fs.existsSync(file)) { if (name !== 'signals') throw new Error('Missing authority: ' + name); return [name, null]; }
  const bytes = fs.readFileSync(file);
  return [name, { bytes: bytes.length, sha256: crypto.createHash('sha256').update(bytes).digest('hex') }];
}));
const journals = ['events', 'effects', 'signals'];
for (const name of journals) {
  if (hashes[name] !== null) parseHashJournal(fs.readFileSync(files[name]), files[name]);
}
const events = parseHashJournal(fs.readFileSync(files.events), files.events).map(record => record.entry);
const completed = events.filter(e => e.type === 'attempt.completed');
const snapshot = { hashes, attemptsUsed: completed.length,
  outcomes: completed.map(e => e.payload.result.outcome),
  resolutions: events.filter(e => e.type === 'wait.resolved').length };
const [name, compare] = process.argv.slice(2);
if (compare) assert.deepEqual(snapshot, JSON.parse(fs.readFileSync(path.join(root, compare + '.authority.json'), 'utf8')));
fs.writeFileSync(path.join(root, name + '.authority.json'), JSON.stringify(snapshot, null, 2) + '\n', { flag: 'wx', mode: 0o600 });
NODE
}
