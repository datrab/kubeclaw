## Content authority decision

The catalogue no longer asks the generator to invent practical explanations.

- `AP08-catalogue-guidance.json` owns the authored purpose, use, exclusion, and limit.
- Package manifests, schemas, metadata, tests, and the AP08 inventory own mechanical facts.
- `AP08-local-verification.json` owns dated local command results and environment limits.
- `docs-publication.mjs` joins these sources into the published pages.

This design has one important cost: a package change can require updates in more than
one authority. The checker rejects missing, duplicate, stale, or unmatched records.
This cost is preferable to silent replacement of reviewed prose with generic text.
