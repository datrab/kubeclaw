## Decision and evidence boundary

Do not mark AP08 complete. The reader can distinguish the extension surfaces and
complete the local minimal-plugin exercise after the fixes below. The reader
cannot complete every requested installation, recovery, and live observation path.
Exact blockers appear in the reader matrix and the remaining-work section.

This review used repository documents, manifests, schemas, code, configuration,
roles, and tests. It did not use earlier conversations. Earlier checkpoint claims
were treated as claims to check. Their results remain historical and are not added
to this review's counts. No product implementation was changed to make a test pass.

All 51 catalogue pages were read individually. Shared byte-identical paragraphs
were reviewed once; package-specific content was reviewed per page. The review
compared manifest declarations, schema facts, operation/error branches, package
guides, and test commands. It did not read every transitive implementation line or
certify every semantic assertion in all 707 source links. This is an explicit
remaining acceptance boundary, not a claim of exhaustive code verification.

The four required starting documents were read in full before the detailed review:
AP08-plan, the documentation quality standard, AP08.7–AP08.9 checkpoint, and the
Extend index. The seven named guides, catalogue index, 51 pages, and linked package
guides supplied the subsequent reader paths. STE-oriented wording was inspected;
a licensed Issue 9 dictionary review was not performed.
