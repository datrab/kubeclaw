# 01 Test Suite Catalogue

Every current test/verification file is classified by release-signal value. New contract-first acceptance tests added during closure are included as CONTRACTED release gates.

Classification meanings: KEEP can remain as-is or with minor drift-guard use; REWRITE should be replaced by a contract-first acceptance test; DELETE only after replacement; QUARANTINE is documentation/stale evidence/helper artifact not safe as executable truth.

Status meanings: CONTRACTED proves a named contract helper or live/runtime boundary; TESTED proves local behavior but not full contract closure; UNTESTED means no executable proof; AMBIGUOUS means the current test is too weak as a contract; BROKEN means the asserted behavior indicates an invalid or unsafe contract state.
