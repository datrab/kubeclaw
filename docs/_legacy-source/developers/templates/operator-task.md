# Operator Task Template

Status: template
Audience: documentation authors

## Purpose

Use this template for deployment and operations procedures.

```text
# Task name

What this page helps the operator do.

## When to use this
## Before you begin
## What happens
## Procedure
## Verify the result
## Expected output or state
## Common failures
## Recovery
## Related reference
## Sources
```

## Required Content

- Purpose and audience.
- Prerequisites, including access, namespace, local tools, values files, and upstream prerequisites.
- Exact commands from the repository root unless another working directory is stated.
- Expected state or output after important commands.
- Verification commands and success criteria.
- Common failures with checks and recovery steps.
- Related references for exact values.
- Source list only when implementation-specific behavior is described.
