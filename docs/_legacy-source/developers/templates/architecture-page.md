# Architecture Page Template

Status: template
Audience: documentation authors

## Purpose

Use this template for mental models and system explanation.

```text
# Architecture topic

## Overview
## Components
## Runtime flow
## State and ownership
## Failure behavior
## Operator implications
## Related tasks
## Sources
```

## Required Content

- Current behavior only, unless planned behavior is clearly labeled.
- Component ownership and data boundaries.
- Runtime flow and state transitions where relevant.
- Failure behavior and operator implications.
- Links to procedures instead of long embedded task instructions.
