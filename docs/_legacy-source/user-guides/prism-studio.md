# Prism Studio user guide

1. Nova sends the accepted architecture to Prism.
2. The Prism OpenClaw agent creates exactly three materially distinct directions.
3. Open the private Tailscale Studio address and select a direction.
4. Use the visual editor for deterministic insert, move, copy, edit, or remove operations.
5. Enter a natural-language change request when Prism should redesign something.
6. Studio sends that request back to the same project-scoped OpenClaw session and waits for the committed revision.
7. Use Preview mode to test screens, states, and flows.
8. Review all blocking and review findings, approve the exact revision, and publish its immutable Baseline Bundle.

Puck supplies editor controls. Puck does not own the design. Prism stores only
the validated Design Document and typed edit operations.

Studio and Discord are two interfaces to the same logical Prism agent. Control,
Studio, worker, and Envoy are supporting components, not additional agents. The
worker renders and evaluates documents; it does not call an LLM.
