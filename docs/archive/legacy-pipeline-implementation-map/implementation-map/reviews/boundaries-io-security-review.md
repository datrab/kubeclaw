# 1. Domain Health Assessment

The perimeter maps show good local hardening in several places: strict CLI parsing is documented for Nova (`env-vars-and-inputs.md:P00a-E002`), gate artifact paths are centrally bounded by OI-39 (`external-boundaries.md:OI39-X001`, `env-vars-and-inputs.md:OI39-E001`), high-authority Git operations are called out explicitly (`external-boundaries.md:P03-X004`), Buster unit-test command tokenization rejects shell metacharacters (`external-boundaries.md:B03-X008`), and raw operator prompt ingress is bounded/fenced by RV-06. The remaining weak point is consistency across unresolved execution surfaces: environment defaults, broad Docker/Kubernetes/browser tooling, and some noncritical/degraded paths can still cross into runtime execution paths. Several boundaries are documented as “best effort”, “missing binary skips”, or “failures degrade”, which is acceptable for observability but too loose for execution surfaces that can mutate Git, Redis, Kubernetes, containers, or Discord/operator channels.

# 2. Critical Structural Flaws (Must Fix)

1. **External tool execution can inherit the full process environment, including secrets.**  
   `env-vars-and-inputs.md` documents live secrets and credentials in process environment inputs: Discord webhook URLs (`P01-E002`, `P03-E008`, `B00a-E002`, `P23a-E004`), gateway tokens (`P03-E005`, `B00a-E004`, `C00b-E003`), Redis passwords (`P03-E006`, `P16-E006`, `B00a-E001`, `B02b-E004`), and Discord purge/media tokens (`C00a-E001`, `B04-E010`). The lint subprocess layer then explicitly uses “current process env plus `opts.env`” for `safeExec` (`env-vars-and-inputs.md:P23b-E005`) across many PATH-resolved tools (`dependency-matrix.md:P23b-DEP003`, `P23b-DEP004`, `P23b-DEP005`, `P23b-DEP006`) through the external execution boundary (`external-boundaries.md:P23b-X001`). This is a direct secret-sprawl boundary: unrelated linters and scanners can receive deployment credentials unless a deny-by-default environment allowlist is specified.

2. **Verification DI seams were part of runtime configuration instead of being isolated to verification harnesses. — Resolved by RV-02.**
   Runtime config now rejects `_testOverrides`, and the production maps cite explicit invocation-scoped dependency injection (`opts.deps` or adapter-specific override parameters) instead of config-carried test seams for Redis/project-summary adapters (`env-vars-and-inputs.md:P02-E007`, `P02-E008`), Discord/embed delivery (`P03-E003`), pipeline runner dependencies (`P06-E003`), module/gate/review/approval runners (`P08-E001`, `P10-E008`, `P11-E001`, `P12-E001`), and architecture validation (`P19-E001`). Verification rows now describe these as harness-only DI objects (`env-vars-and-inputs.md:V02a1-E002`, `V02a1-E003`, `V02a2-E003`, `V02a3-E003`, `V03a-E007`).

3. **Redis transport policy is centralized and secure by default. — Resolved by RV-03.**
   Nova task/adapter Redis, telemetry Redis, completion event adapters, and Buster queue/telemetry/tooling now construct clients through the shared `redis-transport.ts` contract. The maps require password, TLS, or documented network isolation for non-local Redis (`env-vars-and-inputs.md:P03-E006`, `P16-E006`, `B00a-E001`, `B02b-E004`, `B05-E005`; `external-boundaries.md:P03-X005`, `B00a-X001`, `B02b-X001`, `B02b-X002`, `B05-X002`; `dependency-matrix.md:P03-DEP003`, `B02b-DEP001`, `B05-DEP003`). Unauthenticated Redis is limited to explicit localhost verification factory options and otherwise throws `RedisTransportPolicyError` fail-closed.

4. **Buster execution surface is too broad for task-configured inputs.**  
   Buster task/config inputs can drive build, unit, API, E2E, Kubernetes, and browser/media flows (`env-vars-and-inputs.md:B00a-E006`, `B03-E001`, `B03-E004`, `B03-E006`, `B03-E008`, `B04-E001`-`B04-E010`). The corresponding boundaries include `sandbox-build`, `nginx`, `podman`, `kubectl`, `curl`, `npx playwright`, Lighthouse, `du`, local HTTP/WS, browser automation, `/sandbox`, `/tmp`, and Discord media upload (`external-boundaries.md:B03-X001`-`B03-X008`, `B04-X001`-`B04-X006`, `B05-X001`). The maps mention specific safeguards only for K8s namespace prefixes and unit shell metacharacters (`external-boundaries.md:B03-X005`, `B03-X008`), while dependencies show production image build/push and cluster apply/wait/status capabilities (`dependency-matrix.md:B03-DEP003`, `B03-DEP004`). The perimeter lacks a single capability gate saying which task types may invoke container/Kubernetes/browser/Discord media operations.

5. **Prompt ingress is bounded, redacted, fenced, and prompt completion protocols are typed. — RV-06 and RV-05 resolved.**
   Operator `--prompt`/`--prompt-file` now enters through `services/prompt-ingress.js` (`env-vars-and-inputs.md:P00a-E009`, `P00a-E010`; `prompts-and-agent-behavior.md:P00a-PR001`), which enforces size limits, repo-root realpath policy for prompt files, `[REDACTED_SECRET]` placeholders, and XML-style untrusted remediation fences for Forge/review fix prompts (`prompts-and-agent-behavior.md:P07-PR001`, `P10-PR002`). Forge, Buster module/gate, and review prompts now declare exact raw-JSON artifact/output schemas, explicitly forbid Markdown/fenced output, and rely on pipeline-side validators/readers after write (`prompts-and-agent-behavior.md:P22-PR001`-`P22-PR004`, `env-vars-and-inputs.md:P22-E009`, `external-boundaries.md:P22-X002`, `P22-X004`). Gate/review fix prompts declare constrained action contracts: agents may only edit required project files and must not write status/completion/gate-output/Redis signals or run git finalization (`prompts-and-agent-behavior.md:P22-PR005`).

6. **Delivery-lint Dockerfile/static paths are boundary-controlled. — Resolved by RV-07.**
   Delivery lint now remains contextual for modules without `test_config.serve.dockerfile`, but declared Dockerfiles must be repo-root-relative and pass `core/paths.js` realpath jailing inside `config.repo_root` before any read (`env-vars-and-inputs.md:P02-E013`, `external-boundaries.md:P02-X006`, `dependency-matrix.md:P02-DEP003`, `path-construction.md:P02-P007`). Absolute paths, traversal, symlink escapes, missing files, read failures, and invalid or symlink-escaped static paths return fail-closed validation results.

7. **Secret redaction is not defined as a single policy for stdout/stderr/audit/summary surfaces.**  
   Some helper paths are described as sanitized/redacted (`external-boundaries.md:P00b-X005`, `P03-X001`), but core runtime logging always emits JSON to stderr before best-effort file append (`external-boundaries.md:P01-X005`), runtime status/dry-run output goes to stdout/human output (`external-boundaries.md:P06-X006`), Discord audit writes happen before delivery gates (`env-vars-and-inputs.md:P03-E002`; `external-boundaries.md:P03-X002`), and project summary collectors scan progress/status/verdict/spec/review/prompt artifacts before optional Discord delivery (`external-boundaries.md:P23a-X002`, `P23a-X003`). Pipeline review also instructs a spawned agent to read saved prompts and statuses (`prompts-and-agent-behavior.md:P20-PR001`). The maps do not show a universal redaction contract for these egress surfaces, so prompt/config secrets can leak even when webhook delivery is disabled.

# 3. Simplification & Consolidation Targets (Should Fix)

1. **Introduce one environment allowlist for every subprocess/tool boundary.** Apply it to P23b lint tools, B03/B04 Buster tools, P21 lint-report subprocess, Git subprocesses, and lifecycle cleanup commands. Do not pass ambient `process.env` except explicitly required keys (`PATH`, tool-specific CI flags, and narrowly scoped credentials when unavoidable). Evidence: `env-vars-and-inputs.md:P23b-E005`, `B03-E009`; `external-boundaries.md:P21-X001`, `P23b-X001`, `B03-X002`-`B03-X008`, `B04-X003`; `dependency-matrix.md:P23b-DEP003`-`P23b-DEP006`.

2. **Resolved RV-02: remove test overrides from production config shape.** Runtime config containing `_testOverrides` now fails validation, and runtime rows use explicit invocation DI available only in verification entrypoints or harness constructors. Evidence: `env-vars-and-inputs.md:P02-E007`, `P02-E008`, `P03-E003`, `P06-E003`, `P08-E001`, `P10-E008`, `P11-E001`, `P12-E001`, `P19-E001`, and verification consumers `V02a1-E002`, `V02a1-E003`, `V02a2-E003`, `V02a3-E003`, `V03a-E007`.

3. **Resolved RV-03: collapse Redis configuration into one authenticated transport policy.** The maps now point Nova, telemetry, completion event adapters, Buster queue, and Buster telemetry/tooling at one shared Redis transport contract. Non-local Redis client construction fails startup unless password, TLS, or documented network isolation is configured; unauthenticated localhost is verification-only through explicit factory options. Evidence: `env-vars-and-inputs.md:P03-E006`, `P16-E006`, `B00a-E001`, `B02b-E004`, `B05-E005`; `dependency-matrix.md:P03-DEP003`, `B02b-DEP001`, `B05-DEP003`.

4. **Split Buster deterministic suites into capability-scoped profiles.** Keep API/unit/static checks in the default profile; require explicit config for container build, Kubernetes apply, browser automation, Lighthouse, visual audit/media upload, and image pre-pull. Evidence: `external-boundaries.md:B03-X002`-`B03-X006`, `B04-X001`-`B04-X006`, `B05-X001`; `dependency-matrix.md:B03-DEP001`-`B03-DEP008`, `B04-DEP001`-`B04-DEP008`, `B05-DEP001`.

5. **Resolved RV-05: replace prompt-embedded shell protocols with typed artifact/action contracts.** Forge/Buster/review prompts now declare exact raw-JSON schemas and forbid Markdown/fenced output; legacy prompt shell/Node artifact writers were deleted. Fix prompts declare allowed actions explicitly and forbid status/completion/gate-output/Redis writes plus git finalization. Evidence: `prompts-and-agent-behavior.md:P22-PR001`-`P22-PR005`, `external-boundaries.md:P22-X002`, `P22-X004`, `env-vars-and-inputs.md:P22-E009`.

6. **Resolved RV-07: boundary-control delivery-lint file inputs.** Declared Dockerfile paths are repo-root-relative, realpath-jailed through `core/paths.js`, and fail closed on absolute/traversal/symlink/missing/read failures, including existing static-path symlink escapes; modules without a declared `serve.dockerfile` remain pass-through. Evidence: `env-vars-and-inputs.md:P02-E013`, `external-boundaries.md:P02-X006`, `dependency-matrix.md:P02-DEP003`, `path-construction.md:P02-P007`.

7. **Define one redaction/egress policy for logs, audit files, summaries, and spawned review agents.** The policy should cover stdout/stderr JSON, Discord audit JSONL, project summaries, pipeline reviews, prompt artifacts, and disabled-webhook audit behavior. Evidence: `external-boundaries.md:P01-X005`, `P06-X006`, `P03-X002`, `P23a-X002`, `P23a-X003`; `env-vars-and-inputs.md:P03-E002`; `prompts-and-agent-behavior.md:P20-PR001`.

8. **Redis dependency loading is native and single-path. — Resolved by RV-09.** The shared `redis-transport.ts` loader now performs exactly one native Node package lookup, `require('ioredis')`, and missing packages throw structured `MissingDependencyError` diagnostics. Obsolete multi-candidate loading and wrapper-only constructor surfaces were deleted. Evidence: `external-boundaries.md:P00b-X004`; `dependency-matrix.md:P00b-DEP008`, `P03-DEP003`, `B01-DEP007`, `B00a-DEP002`.
