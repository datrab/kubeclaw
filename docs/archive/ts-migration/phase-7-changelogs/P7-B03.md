## Behavior changes

### DELETE_LEGACY
- Deleted function-valued rate-limit fallback options.
  - `resolveRateLimitOption()` now rejects callback values instead of invoking late fallback functions.
  - Buster/review gate, case-study, and pipeline-review callers pass resolved typed identity values and use explicit tracked correlation refresh where identity can change during a cooldown cycle.
- The active Forge completion authority was already strictified in `agent-observability-forge-completion.ts`: missing `repo_root` now returns typed failed diff authority evidence with source `repo_root_required`, not a successful no-work result.

### STRICTIFY_TS_SLICE
- Remediation handoff requests now require typed gate identity and remediation policy fields.
  - `producerType`, `gateId`, `gateType`, `runId`, `attempt`, `policy.maxFixCycles`, `policy.nextFixCycle`, `policy.rerunStageId`, `targetRef`, and `startedAt` must be present.
  - Hidden null/default remediation fields and the `gate:<unknown>` rerun-stage default were removed.
- Active-session authority now requires canonical string attempt identity.
  - Numeric attempts are no longer normalized into authoritative active-session identity.
  - Contract tests now assert numeric attempts are not strong lifecycle authority identity.
- Migrated support-service owners now run as native erasable TypeScript while retaining only pure `.js` path facades.

### KEEP_TYPED_POLICY retained
- ACP monitor recovery sampling keeps bounded defaults and sparse monitor-detail handling.
- Approval signal adapter failures remain runner-consumable fatal events; debounce, cancellation, and terminal cleanup remain explicit filesystem-edge policy.
- Artifact fallback surfaces remain diagnostic evidence only and cannot gain lifecycle, scheduler, completion, ordering, or session authority.
- Compatibility-authority stripping still removes known legacy authority keys recursively with circular-reference protection.
- Contract diagnostics still produce redacted invalid-plugin diagnostics without preserving compatibility authority.
- Dependencies still reject legacy gate PASS/APPROVED without canonical completion output.
- Durable operator alerts remain local-first evidence before network/sink delivery.
- Failure text classification and incidents remain operator-facing support logic, not primary authority.
- Legacy Forge completion artifact reading remains a narrow typed external adapter and is not the hook/diff completion authority.
- Gate active-session files and tracked agents remain diagnostic recovery evidence; lifecycle read models stay authoritative.
- Gate fix scaffold prompt/transcript writes remain redacted observability artifacts.
- Governance context remains in-memory summary support and does not replace canonical artifacts.
- Prompt ingress keeps bounded, redacted operator text and inline CLI prompt precedence.
- Rate-limit cooldown defaults, nonblocking Discord/telemetry notices, durable cooldown replay, and durable exhaustion finalization remain typed runtime policy.
- Redis completion keeps invalid-entry diagnostics, canonical source authority, duplicate idempotence, conflict fail-closed behavior, and active-identity archive exclusion.
- Redis log mirrors remain bounded, serializable observability side effects.
- System I/O warning emission drops malformed warnings and falls back to sanitized stderr when telemetry fails.
