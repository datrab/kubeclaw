## Behavior changes

### DELETE_LEGACY
- Deleted Gate Forge fix transcript no-change authority.
  - No-change fix attempts are now classified from typed session result evidence (`timeout` vs `no_file_changes`) instead of transcript progress heuristics.
- Deleted Review first-reviewer remediation fallback.
  - Review remediation requests now require an explicit `reviewerLabel` or typed `primaryReviewer`; the code no longer silently selects `reviewers[0]` when identity is missing.
- Deleted Review output `PASS`/`FAIL` aliases.
  - Review parsing and existing-output resume checks accept canonical `GO` and `NO-GO` only.
- Deleted soft-pass review publication failure.
  - Review output commit/push degradation now returns a typed failed review result with `output_publication_failed` instead of allowing the gate to pass on unpublished evidence.

### STRICTIFY_TS_SLICE
- Review remediation limits no longer fall back to `config.default_max_fails`.
  - Remediation request/build/exhaustion paths require typed review/remediation `maxFixCycles` policy.
- Review Forge fix timeout no longer falls back to `config.default_timeout_minutes`.
  - Fix attempts use the typed review timeout policy.
- Approval audit write failures remain nonterminal but now emit durable operator-alert evidence instead of being swallowed.
- Review config resolution was narrowed to gate/review defaults for typed review fields rather than global pipeline fallback authority.

### KEEP_TYPED_POLICY retained
- Approval gate corrupted/invalid state still fails closed with operator-visible repair context.
- Approval resolved-state replay, pending-state resume, and explicit timeout continue/block policy remain intact.
- Remediable-gate malformed remediation policy still fails safe to exhausted control result.
- Review no-grounded-issues terminal escalation and first-cycle-only operator directive policy remain intact.
- Review cleanup and review evidence fan-out remain best-effort observability side effects.
- Review default NO-GO routing to fix-and-rereview remains the intentional default policy.
