## Behavior changes

- `openclaw.subagent.spawning` no longer promotes through the temporary `plugin.event` fallback. It now emits canonical typed telemetry as `agent.spawn.requested`.
- `openclaw.subagent.delivery_target` no longer promotes through `plugin.event`. It now emits canonical typed telemetry as `agent.delivery.target`.
- Agent-observability mapper output for the two promoted events is bounded to typed routing/correlation metadata; raw requester/routing payloads remain in the agent-observability control stream.
- Canonical telemetry contract and payload schema now include `agent.spawn.requested` and `agent.delivery.target`.

## Imports, docs, and tests updated

- No new broad barrels or compatibility layers were added.
- Docs updated in `docs/lifecycle-unification/TELEMETRY_CONTRACT_V1.md` and `docs/telemetry-event-schema.md` for the two new canonical agent telemetry events.
- Contract/behavior tests updated to assert first-class mapping and ingester emission for spawn-request and delivery-target events.

## Ledger compliance

### KEEP_TYPED_POLICY retained

- Common agent-observability LLM payload non-promotion retained: LLM input/output still map to summary telemetry with `promoted_by_default: false`; raw prompts/responses remain on payload streams.
- Common agent-observability minimal masking profile retained unchanged: obvious API-key/token/secret/authorization patterns are masked with metadata; broader DLP remains outside this batch.
- Common rate-limit recovery action fallback retained as typed policy: `resolveRateLimitRecoveryAction()` still resumes when gateway liveness is unknown or the session is live, and kills only confirmed non-live sessions.
- Explicit Anthropic provider default policy remains opt-in through `allowAnthropicDefault: true`; no silent provider default is introduced.

### STRICTIFY_TS_SLICE strictified

- Common agent-observability temporary `plugin.event` mappings were strictified: spawn-request and delivery-target now use first-class canonical telemetry schemas (`agent.spawn.requested`, `agent.delivery.target`) instead of plugin-event fallback authority.

### DELETE_LEGACY deleted

- Nova contract namespace barrel remains deleted: `skills/nova/pipeline/services/contracts/index.ts` is absent, and callers/tests use direct owning contract modules.
- Redis completion canonical-envelope opt-in legacy is not retained: active completion validation defaults require canonical envelope and completion stream role (`requireCanonicalEnvelope: opts.requireCanonicalEnvelope !== false`, `expectedStreamRole: 'completion'`).
