## Behavior changes

### DELETE_LEGACY
- Deleted JavaScript runtime sidecar owners after migration to native erasable TypeScript:
  - `agent-observability-runtime.js`
  - `openclaw-plugin-runtime.js`
- Deleted permissive runtime-config string coercion for ingester config fields.
  - Runtime config booleans must be booleans.
  - Runtime config numeric fields must be positive/non-negative integers as documented.
  - Redis port runtime config must be an integer in `1..65535`.
  - Redis network-isolation runtime config must be a boolean or non-empty string.
- Deleted implicit acceptance of malformed runtime config values that previously flowed through `Boolean(...)`, `Number(...)`, or generic string normalization.

### STRICTIFY_TS_SLICE
- Strictified `agent-observability-ingester/config.ts` into one typed config boundary.
  - Sparse runtime config still receives typed defaults.
  - Deployment environment values remain accepted only at the explicit env boundary.
  - Runtime config no longer silently string-coerces typed fields.
- Strictified runtime sidecar loop failures.
  - Loop failures still do not crash orchestration.
  - The first loop failure now emits typed degraded evidence with reason `agent_observability_ingester_loop_failed` and source `agent_observability_ingester_runtime` before continuing.
- Added contract coverage proving disabled ingester runtime remains a no-op and enabled runtime failures produce typed degraded evidence.

### KEEP_TYPED_POLICY retained
- Ingester disabled/no-op rollout remains explicit and nonfatal.
- Ingester `BUSYGROUP` handling remains idempotent for restarts.
- Poison control records remain dead-lettered and ACKed so invalid telemetry cannot block the consumer group.
- Optional Redis adapter-method fallbacks remain narrow external-adapter policy:
  - missing reclaim support returns no pending records
  - missing trim is a no-op
  - shutdown uses `quit` or `disconnect`, with close failures logged before fallback
- Evidence comparator and hook-taxonomy adapters remain evidence-only external adapters; they do not become lifecycle or completion authority.
- Runtime sidecar disabled state remains `{started:false}` with no-op stop/null stats.
- Runtime sidecar loop defaults remain bounded policy: 250ms loop delay and health check every 10 ticks when omitted.
- Plugin controller remains config-gated and optional.
- Plugin controller defaults remain bounded policy: `openclaw plugins enable|disable kubeclaw-agent-observer` with a 10s timeout.
- Plugin cleanup failures remain nonterminal and do not mask pipeline terminal results.
