## Behavior changes

### DELETE_LEGACY
- Deleted configured pre-check lint pass/skip behavior when lint-report tooling is missing.
  - `generateLintReport()` now reports `LINT_REPORT_TOOL_MISSING` as typed setup failure evidence.
  - `runPreCheck()` fails closed with `LINT_PRECHECK_EVIDENCE_REQUIRED` instead of passing without report evidence.
- Deleted configured pre-check lint pass/skip behavior when lint-report JSON is unparseable.
  - Unparseable report output now records `LINT_REPORT_UNPARSEABLE` setup diagnostics and fails closed.
- Deleted hard-budget read/check failure default-to-not-exceeded behavior.
  - `isBudgetExceeded()` now treats budget evidence errors as exceeded pending operator review.
- Deleted legacy cumulative-summary aggregation from best-effort per-module `status.json` scans.
  - `buildCumulativeSummary()` now uses typed `progress.run_stats.cumulative` or `progress.cumulative` read-model evidence.

### STRICTIFY_TS_SLICE
- Strictified Gateway aborted Nova injection handling.
  - Aborted Gateway responses are no longer marked `ok_aborted`/delivered without acknowledgement.
  - The injection audit entry now records `delivery_unknown_aborted`, preserves the abort error, sets `delivery_acknowledged: false`, and emits a critical manual-verification notice.
- Strictified module validator producer authority.
  - Built-in validator stages now receive explicit typed `producerType` values.
  - Missing producer metadata returns a blocked validator-control result with `invalid_validator_metadata` instead of deriving producer identity from the stage id string.
- Strictified pipeline-review config source resolution.
  - Pipeline review now uses one typed config source (`config.pipeline_review` preferred, otherwise `progress.pipeline_review`) instead of implicitly merging progress over config.

### KEEP_TYPED_POLICY retained
- Deterministic/offline architecture validation remains intact.
- Architecture validator artifact writes remain nonterminal observability side effects.
- Lint-report nonzero process exit with valid JSON output remains accepted as lint evidence.
- Lint temp cleanup and archive writes remain noncritical beside lint verdict authority.
- Full-lint missing/tool-failure blocking behavior remains intact.
- Observability structured event, invalid telemetry payload, duplicate suppression, usage/cost artifact, and cost-report writes remain nonterminal observability policy except for the hard-budget fail-closed check above.
- Pipeline-review and case-study optional generator failures remain typed generator results instead of pipeline crashes.
- Pipeline-review Discord post failure remains diagnostics-only when authoritative review artifacts exist.
- Case-study deterministic artifact paths, rate-limit recovery, sanitization, and best-effort notification/transcript side effects remain intact.
