## One persistence predicate

A supported plugin operation initiates or owns a retained write: explicit brokered artifact/evidence emission, source commit, append/store mutation, or intentional external retained-state operation. Its downstream owner and lifetime must be stated. No plugin-owned replay journal is required. Reading/returning existing values alone, generic caller-selected commands/HTTP methods, incidental platform logs/implicit effect journals, volatile queues, or temporary setup removed within the same operation are not by themselves such a feature. Failure/rejection is not a successful write receipt. Classification asks whether a supported path has the responsibility, not whether every invocation writes.
