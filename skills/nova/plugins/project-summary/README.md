# Project summary

Deterministically renders a canonical project/run summary from closed facts.
This package deliberately has no agent capability: summary calculation and
formatting are code, not judgment.

The current extraction owns status and aggregate metric validation, stable
Markdown rendering, diagnostics, and immutable JSON evidence through the real
v2 runner. Repository census, Git statistics, lifecycle fact collection,
latest-pointer publication, operator presentation, and the ownership split
with core terminal evidence remain explicit parity blockers.
