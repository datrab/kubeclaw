# Case study protocol

Owns an evidence-only case-study instruction protocol and validates generated
Markdown against six required, ordered sections. The response must correlate
to the requested project/run, reject unknown fields and unsafe control
characters, and is stored only after validation.

The local test uses the real authenticated v2 dispatch and artifact path
without spawning an agent. Writer judgment, factuality against source
artifacts, session lifecycle, transcripts, output-file watching, rate-limit
recovery, and presentation remain explicit final parity blockers.
