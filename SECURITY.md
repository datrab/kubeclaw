# Security Policy

## Reporting security issues

This repository does not yet publish a maintainer-selected public security contact or disclosure channel. Do not disclose exploitable issues publicly before maintainers have selected one. Use the private maintainer coordination channel available to your repository access, then track any source-backed remediation in `docs/status/open-issues.json`.

The missing public security contact is recorded in [Open Issues](docs/site/status/open-issues.md).

## Current documented security surfaces

- [Deployment and Trust](docs/site/understand/deployment-and-trust.md) explains Kubernetes RBAC, workload isolation, networking, and deployment boundaries.
- [Secrets](docs/site/reference/secrets.md) lists generated Secret ownership, use, rotation, and failure behavior.
